# CodeAlpha File Organizer

A Python-based file organizer developed as part of my CodeAlpha Python Programming Internship.

## Project Overview

This project automatically moves JPG images from a source folder to a destination folder using Python.

## Features

- Organizes JPG images automatically.
- Accepts source and destination folder paths.
- Moves images to the specified destination.
- Displays the number of files moved.
- Provides a completion message.

## Technologies Used

- Python 3
- os module
- shutil module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python file_organizer.py

5. Enter the source folder path when prompted.
6. Enter the destination folder path when prompted.

## Example

Source folder:
C:\JPG_Test_Source

Destination folder:
C:\JPG_Test_Destination

The program moves JPG images from the source folder to the destination folder.
